# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be welcoming, be respectful, assume good intent, and keep discussions about the
work. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other
project space.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@25LioN52](https://github.com/25LioN52), using the contact details on their GitHub profile. If the behaviour
involves the maintainer, use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature instead. All reports are handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that violate this
code of conduct, and may temporarily or permanently ban contributors, following the enforcement guidelines of the
Contributor Covenant.
