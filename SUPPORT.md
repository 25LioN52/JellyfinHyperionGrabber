# Getting help

1. **Check the docs:** the [troubleshooting guide](https://25lion52.github.io/JellyfinHyperionGrabber/user-guide/troubleshooting/)
   and [FAQ](https://25lion52.github.io/JellyfinHyperionGrabber/user-guide/faq/) cover the common problems
   (wrong port, Docker networking, LED layout, priorities).
2. **Ask in [GitHub Discussions](https://github.com/25LioN52/JellyfinHyperionGrabber/discussions)** for setup questions.
3. **Open an [issue](https://github.com/25LioN52/JellyfinHyperionGrabber/issues/new/choose)** for bugs and feature
   requests.

Always include the plugin version, Jellyfin version and installation type (Docker, native), the client app,
the Hyperion.ng or HyperHDR version, and the Jellyfin log lines that mention `HyperionGrabber`.
