Hyperion Grabber

Help

Streams the video you are watching to Hyperion.ng or HyperHDR for ambient lighting. LED layout, colors and smoothing are configured in Hyperion; this plugin only sends the picture.

Early preview: the lights follow playback of library videos on the devices you select. If Hyperion restarts during playback, the lights come back with the next playback.

Hyperion server

Host name or IP address of the machine running Hyperion.ng or HyperHDR. If Jellyfin runs in Docker, localhost only works with host networking.
Default 19400. This is the FlatBuffers server port, not the web UI port (8090) or the JSON port (19444).
100-199, lower wins. Default 150 overrides Hyperion's own capture (240+) and background effects.
The test pattern shows red at the top, green on the right, blue at the bottom and yellow on the left, with a white light running clockwise from the top-left corner. If the sides or direction are wrong, fix the LED layout in Hyperion.

Playback

Only playback on the devices selected below drives the lights.
Pictures per second sent to Hyperion, 1-60. Default 25 looks smooth; lower it if the Jellyfin server is short on CPU. Applies from the next playback.

Devices

Devices with a recent Jellyfin session, most recent first. If your TV is missing, start playing something on it and press Refresh.

Users (optional)

Leave all unticked to react to every user, or tick users to react only to them.
